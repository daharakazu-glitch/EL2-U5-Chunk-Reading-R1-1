# EL2-U5-Chunk-Reading-R1-1

E.C. II Unit 5: What can we learn from traveling?
Reading 1 Part 1: The Rise of the Gap Year

チャンクリーディング & 暗誦・リスニング・発話練習アプリ

## 機能
- **チャンクリーディング & 穴埋め**: ヒント付きの空所をクリックして正解を表示／非表示
- **音声録音 & 再生**: マイク録音による発音練習
- **進捗表示 (Progress)**: 回答済み数のカウント表示
- **解答順次表示 (Next Answer)** / **全表示 (Show All)**
- **音声読み上げ (TTS)**: チャンクごとの連続再生（ハイライト連動）および行ごとの音声再生
- **日本語訳 表示切替 (ON/OFF)**
- **リセット機能**
